# Tic-Tac-Toe Agent
An intelligent agent that learns and plays Tic Tac Toe

This project contains 4 core modules
1. Environment
2. Agent
3. Trainer
4. Evaluation

## Planned Project Architecture 
```
tictactoe-agent/
├── game/            # Environment
├── agents/
├── training/        # Training loop
├── evaluation/      # Benchmarking
├── visualization/   # Plots and demos
├── scripts/         # CLI entry points
└── models/          # Saved models
```
